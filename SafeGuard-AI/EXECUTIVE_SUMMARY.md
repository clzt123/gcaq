## 🏗️ 四大核心亮点

### 🤖 Phase 1 — 智能核心 (AI Core)

> *"让 AI 看懂工厂，看懂风险"*

- **全链路闭环**: 图片输入 → Qwen-VL 视觉分析 → GraphRAG 知识增强 → 记忆系统注入 → 工单生成 → MCP 推送
- **121 个单元测试，0 失败 0 警告**
- 4 大真实工业场景端到端验证（油渍泄漏 / 消防通道堵塞 / 未戴安全帽 / 化学品烟雾），全链路 <25s
- Docker Compose 一键部署（Neo4j + Redis + Milvus + FastAPI 四服务）
- LangSmith 全链路可观测性追踪

### 📡 Phase 2 — 边缘智能 (Edge Intelligence)

> *"把 AI 带到工厂最前线"*

- **四路分流架构**: 高置信度(>90%)边缘即时处置 / 模糊场景云端精算 / 低风险静默 / 失败安全上升
- **边缘镜像精简 64%**: 180MB vs 云端 500MB+
- **断网续传**: MQTT 通信协议 + SQLite 离线队列（网络中断自动缓存，恢复后自动冲洗）
- **边缘 API 8 个端点**: 预筛 / 健康探测 / MQTT 心跳 / 离线队列管理

### ☸️ Phase 3 — 云原生 (Cloud Native)

> *"从一台机器到一个集群"*

- **生产级 Helm Chart (24 文件)**: 一键部署 5 个 K8s 服务
- **自动扩缩容 (HPA)**: Cloud API (2-10 副本) + Edge API (2-8 副本)
- **持久化存储 (PVC)**: Neo4j(20Gi) + Redis(5Gi) + Milvus(30Gi)
- **Ingress + TLS**: 生产级流量入口 + cert-manager 自动证书

### 🔄 Phase 4 — 持续学习 (Continuous Learning)

> *"让 AI 越用越聪明"*

- **SFT 微调流水线**: 自动化训练数据导出 (JSONL 格式，LlamaFactory 兼容)
- **A/B 评估框架**: 精确率/召回率/F1 三维对比 + 显著性检验 + 优胜推荐
- **反馈闭环**: 驳回自动触发 → 数据导出 → 微调 → 评估 → 自动切换模型版本
